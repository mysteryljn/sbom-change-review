# Synthetic release fixtures

These hand-written, synthetic documents model a gateway release. They were not generated by a scanner or collected from a vehicle. Names, versions and license assignments are fictional. They use CycloneDX 1.5/1.6 and SPDX 2.3 field layouts; the program validates its supported subset, not the complete schemas.

The pair intentionally demonstrates one changed identity, one addition, one removal, and one ambiguous multi-version change. Reproduction: `sbom-change-review demo --output report.html`. The SPDX document exercises purl matching across formats. To regenerate, edit the ordinary JSON records and run the fixture regression tests; no generator, credentials, or network is involved.
